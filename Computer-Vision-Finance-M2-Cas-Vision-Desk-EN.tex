\section{Question}

\textbf{Closed task.}
You receive a financial image (chart screenshot or document page).
Build a \textbf{Vision Desk}: fine-tune a ViT, expose it through MCP tools,
and let an LLM answer \emph{only} from those tools.

Your deliverable must make three things explicit:
\begin{enumerate}
  \item \textbf{Vision assertion} --- class, score, structured fields the model can support;
  \item \textbf{Tool justification} --- which MCP call and JSON field justify each claim;
  \item \textbf{Refusal} --- what you do not conclude when a tool fails or returns null.
\end{enumerate}

\paragraph{Parallel with Signal Desk.}
Where Signal Desk judged an LSTM \emph{after trading costs}, Vision Desk judges an
LLM agent \emph{after grounding}.

Stubs are accepted for \texttt{market.*} and \texttt{knowledge.*} if they are
documented and deterministic.

\section{Mandatory protocol}

\begin{enumerate}
  \item Split by \textbf{document} (or issuer), not a random mix of pages from the same PDF.
  \item Backbone preprocess as prescribed by the model (ImageNet mean/std or checkpoint docs).
  \item Publish F1 (macro or per class) out of sample + confusion matrix.
  \item Publish the JSON schema \emph{before} test inference.
  \item Every claim in the LLM answer must cite a tool call and a field.
  \item Force a tool-failure scenario and show refuse / retry (not invention).
  \item Forbidden: LLM answer without a tool for a fact ``seen'' in the image.
\end{enumerate}

\section{What you must show}

\begin{itemize}
  \item ViT vs session-1 baseline, with a clean document-level split;
  \item valid JSON on the held-out set (invalid schema = pipeline failure);
  \item one \textbf{grounded} MCP trace (tools $\rightarrow$ JSON $\rightarrow$ final answer);
  \item one \textbf{refusal} after tool failure or null field;
  \item three written limits (layout shift, OCR / capture, hallucination, \ldots).
\end{itemize}

\section{How results are read}

{\color{warn}\textbf{Grading focuses on protocol, grounding, and limits.}}
A clear refusal after tool failure scores better than a polished LLM sentence
with no JSON.

\section{Variant --- Doc Lens}

Same science. Deliverable = small club tool: image upload, MCP call,
exported page (class, JSON, tools, three limits). No chat without a trace.
