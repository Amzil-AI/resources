\section{Question}

\textbf{Tâche fermée.}
Vous recevez une image financière (capture de graphique ou page de document).
Construisez un \textbf{Vision Desk} : fine-tunez un ViT, exposez-le via des outils MCP,
et laissez un LLM répondre \emph{uniquement} à partir de ces outils.

Le livrable doit rendre trois points explicites :
\begin{enumerate}
  \item \textbf{Assertion vision} --- classe, score, champs structurés que le modèle peut soutenir\,;
  \item \textbf{Justification outil} --- quel appel MCP et quel champ JSON justifient chaque affirmation\,;
  \item \textbf{Refus} --- ce que vous ne concluez pas lorsqu'un outil échoue ou renvoie null.
\end{enumerate}

\paragraph{Parallèle Signal Desk.}
Là où Signal Desk jugeait un LSTM \emph{après coûts de transaction}, Vision Desk juge un
agent LLM \emph{après grounding}.

\section{Protocole obligatoire}

\begin{enumerate}
  \item Split par \textbf{document} (ou émetteur), pas un mélange aléatoire de pages du même PDF.
  \item Preprocess du backbone tel que prescrit (mean/std ImageNet ou doc du checkpoint).
  \item Publier F1 (macro ou par classe) hors échantillon + matrice de confusion.
  \item Publier le schéma JSON \emph{avant} l'inférence test.
  \item Toute affirmation dans la réponse LLM doit citer un tool call et un champ.
  \item Forcer un scénario d'échec d'outil et montrer refus / relance (pas d'invention).
  \item Interdit : réponse LLM sans tool pour un fait « lu » dans l'image.
\end{enumerate}

\section{Ce que vous devez montrer}

\begin{itemize}
  \item ViT vs baseline séance~1, avec split propre par document\,;
  \item JSON valide sur le held-out (schéma invalide = échec pipeline)\,;
  \item une trace MCP \textbf{grounded} (tools $\rightarrow$ JSON $\rightarrow$ réponse)\,;
  \item un \textbf{refus} après échec d'outil ou champ null\,;
  \item trois limites écrites (layout shift, OCR / capture, hallucination, \ldots).
\end{itemize}

\section{Lecture du résultat}

{\color{warn}\textbf{La note porte sur le protocole, le grounding et les limites.}}
Un refus clair après échec d'outil est mieux évalué qu'une phrase LLM polie
sans JSON.

\section{Variante --- Doc Lens}

page exportée (classe, JSON, tools, trois limites). Pas de chat sans trace.
